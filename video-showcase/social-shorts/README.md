# Social Shorts

Polished 9:16 self-media samples built on top of the existing video generation stack.

These are not technology comparison slides. They are feed-native creative directions that use Remotion and HyperFrames for the primary visual work, then FFmpeg for final delivery encoding.

## Render

```powershell
.\video-showcase\social-shorts\render.ps1
```
